# 오르카 던전 돌파 — LAST ORIGIN ROGUE OPERATION

라스트오리진 원본 에셋(`E:/LAO/Google_QA/Assets`)으로 만든 **엔터 더 건전 스타일 탄막 로그라이크 슈터**.
캐릭터는 스프라이트 시트가 아니라 `5_LAO_Defence`와 같은 **SD 컷아웃 리그**(프리팹 Transform 트리 + 원본 애니메이션 클립)로
그려지며, 몸체의 팔을 숨기고 **총을 쥔 손만 떼어내 몸 옆에 띄워** 조준 방향으로 회전시킵니다.

## 실행

**`start_game.bat`을 더블클릭**하면 로컬 서버가 켜지고 브라우저로 게임이 열립니다.
창을 닫으면 서버가 꺼집니다. (Python 3 필요 · three.js r128은 `js/vendor`에 포함되어 오프라인 실행 가능)

수동 실행: `python tools/serve.py 8771` → http://localhost:8771

## 조작

| 키보드 | 동작 |
|---|---|
| `WASD` / 방향키 | 이동 |
| 마우스 이동 | 조준 (노란 조준선) |
| 마우스 왼쪽 버튼 / `J` (누르고 있기) | 사격 |
| 마우스 오른쪽 버튼 / `Shift` / `Space` / `K` | 회피 구르기 (무적 시간, 발밑 원형 쿨타임) |
| `F` | 궁극기 (피해를 주면 충전) |

| `Tab` / `M` | 전술 지도 — 클리어한 구역을 클릭하면 그 구역으로 순간이동 (교전 중 불가) |

일시정지 설정의 **자동 조준 보조**를 켜면 가장 가까운 적을 자동으로 조준합니다(기본 꺼짐, 조준점이 대상에 고정 표시).

**게임패드**(표준 배치): 왼쪽 스틱 이동 · 오른쪽 스틱 조준 · `RT` 사격 · `LT`/`A` 회피 · `RB` 궁극기 · `LB` 보조 스킬 · `B` 상호작용 · `X` 재장전 · `Y` 교체 · `Start` 일시 정지 · `Back` 지도 · 십자키 ←↑→ 강화 선택. 메뉴에서는 `A` 확인, `B` 취소, 십자키 대원 선택.

**옵션**(일시 정지): 전체/배경음/효과음/대원 음성 음량 · 음소거 · 화면 흔들림 · 화면 번쩍임(광과민) · 피해 숫자 · 자동 조준 · 시점 당기기 · 사격 토글(누르고 있지 않기) · 적탄 고대비 색 · 조작 안내 · HUD 크기 · 전체 화면 · **키 설정**(행동 키 재지정, 충돌 시 교환).
작전 포기는 두 번 눌러야 실행됩니다. 전술 지도를 여는 동안에는 게임이 멈춥니다.

  히든 대원 치트: 대원 선택 화면에서 **← → 를 4번**(←→←→←→←→) 누르면 LRL, **치트활성화**를 입력한 뒤 **램파리온**(또는 ramparion)을 입력하면 램파리온이 **무작위 카드 자리**에 나타난다 — 그 카드를 골라야 출전한다 (한글·영문 입력 상태 모두 됨).
  모바일에서는 현재 선택된 카드 기준으로 왼쪽·오른쪽 카드를 번갈아 8번(좌→우→좌→우→좌→우→좌→우) 터치하거나, 카드 영역에서 같은 순서로 스와이프하면 LRL이 무작위 칸에 나타나며 바로 선택된다. 각 입력 간격은 2.5초 이내. 무작위 출격 확률은 LRL·램파리온 각각 2%로 유지된다.


  램파리온 궁극기는 `2_LAO_MINI_ACTION/js/rampalion-skill.js`의 폭탄 `RAMPALION_X` 그리기 코드와 사자/중심 오라 원본 이미지를 직접 사용한다. 손 충전 → 전자기 토네이도(0.75초) → 화염 사자(2.15초) → 금색·녹색 빛 합체 → 섬광 돌진(3.8초) → 귀환(약 5.2초) 순서이며, 조준 방향에 맞춰 회전하고 문구는 화면에 똑바로 표시한다. 원본 파일 해시는 `assets/rampalion-bomb/source.json`에 기록했다.

  램파리온(Skin_AGS_Rampart_1 리그)이 체력 0이 되면 원작 전투 진입 동작을 역재생하며 부서져 **램파트**(체력 75 · 공격력 40% · 스킬 불가)가 된다. 120초를 버티면 원작 조립 동작으로 램파리온에 복귀(체력 전부 회복), 램파트가 쓰러지면 작전 불능.

## 배포 (Cloudflare)

- `wrangler.jsonc`의 빌드 단계가 `node tools/build_dist.mjs`를 실행해 `dist/`만 배포한다.
- dist에서는 게임 JS를 terser로 압축·난독화하고, 이미지는 고정 키 XOR 마스크로 섞는다: 이미지 파일은 `<파일>.pak`(원본 제거), JS 안의 `data:image` 는 `pk:<mime>:<마스킹된 base64>`. `js/pack.js`가 `window.PACK`일 때만 메모리에서 되돌린다(.pak 는 createImageBitmap 으로 바로 픽셀, URL 없음).
- 저장소와 로컬 개발(file:// · 개발 서버)은 원본 이미지와 읽기 쉬운 소스를 그대로 쓴다. 쉽게 복사하는 걸 막는 정도이며 완전한 잠금은 아니다.

### 캐릭터 스킬 확인 및 조작

- ESC → 작전 상황에서 현재 대원의 E/F 설명, 쿨타임·충전량, 습득한 스킬 강화를 확인할 수 있다.
- LRL 궁극기는 `2_LAO_MINI_ACTION/js/lrl-skill.js`의 `LRL_X`와 36프레임 원본 동작, 눈빛 충전·화면을 덮는 붉은 빔·효과음을 직접 사용한다. 빔의 실명은 적의 조준 오차를 늘리며, E는 부채꼴 검기 3개를 발사한다. 일반 사격과 E 사용 중 손과 도끼를 유지하며, 도끼는 탄창 소모나 자동·수동 장전 없이 연속 공격한다.
- 램파리온 E: 최대 2초 홀드 충전(이동속도 50%), 놓으면 사자 발사. 최대 충전은 크기 2.4배·피해 2.5배이며 발사 후 쿨타임이 시작된다. 키보드·터치·게임패드 홀드를 지원한다.
- 램파리온 기본 공격: 사거리 7칸의 흰색 레이저. 궁극기는 별도 시전 리그와 레퍼런스의 팔·랜스가 결합된 돌진 이미지를 사용하므로 기본 리그의 본에 시전 자세를 남기지 않는다.

LRL·램파리온은 실제 Unity 프로젝트의 `Sounds/Voice/LRL`, `Sounds/Voice/RampartNS1` 원본 음성을 사용한다. 출처·해시는 `assets/voice/hidden-source.json`에 기록했다. 선택·출격·E·궁극기·피격·승패·전투 경고에 연결되며 설정의 대원 음성 슬라이더를 따른다.
